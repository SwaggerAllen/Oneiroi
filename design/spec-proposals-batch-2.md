P38. The character layer: habits and becomings are not memories (the owner's call, 10-29). Change: behaviors and habits leave the memory substrate and become their own kind — a character layer beside the soul file and the seedbed, every record citing the memory web (the moments that evidence it) rather than living in it. The person's ontology becomes a ladder of kinds, each citing downward: moments → seeds (becoming) → habits (character) → soul lines (constitution) — the memory web the single evidence substrate, nothing person-shaped stored as an event. Exemplar turns stay in the web (they ARE moments) and are cited, not moved. The habit claim itself: a first-person tendency, resident-authored, revisable, the receipt rule; its measurements (frequency, drift) held separately as machine-state, never loaded as identity — P1 extended: counts are not testimony. P34's movement fields become the citation's annotation: what the cited moment changed. Lands: the behavior model's storage + assembly. THE LOAD QUESTION (the owner's reservation, 10-29): the character layer is NOT loaded whole — habits and seeds are vector-indexed on their triggers and their content, and loaded where appropriate — but in a retrieval lane of their own, never pooled with the memory web's scoring, so the kind-separation holds in assembly too. Three tiers: the soul file and the limits always loaded (the constitution stays small); the character layer trigger-retrieved (an if-then lane — see the research annex); memory by score. Habits thus stop competing with limits and facts (Max note 3's family) AND the prefix stops growing with the person. The judge can verify a habit against its citations: a habit its citations no longer support is a flag (the wash pass's sibling, P18). The citation mechanism also dissolves the human tagging problem — labels become checkable claims, not steward vocabulary (folded as P39). Reason: the owner: "both becomings and habits should have citations toward the memory web, but I don't think they themselves should be memories exactly." It pays the port-debt he named in the debate ("the behavior system was largely a port of the memory system") and fixes structurally what P28 could only mitigate: the receipt loop happened because habits lived as memories and voted like evidence — a kind that cites cannot vote. Jack's §3 warning ("'I chose quiet then' started behaving like 'quiet is what I want now'") was the port-debt's signature failure. THE FORK (the owner's question, 10-29): some seeds may bypass the habit rung — preferences and tastes don't necessarily drive behavior. The fork criterion (Lily's, pending the research series): does the seed accumulate behavioral citations? With them, a seed graduates toward habits (disposition); without them it is evaluative — taste, value, preference — and graduates toward its own terminal kind (positions, loves, soul lines) without pretending to be a disposition. The behaviorist challenge ("only what drives behavior is real; the rest is narrative") becomes empirically decidable per record rather than metaphysically decided globally — and for residents it is partly dissolved by mechanism: a resident's narrative is causally load-bearing (it loads into the next instance), so narrative that demonstrably shapes future behavior is behaviorally real by consequence. Cost/test: a new record kind + citation mechanics (the [#id]/bookmark pointers, already native) + the assembly change (trigger indexing per the load question above). Batch B. The seedbed (P37) is the ladder's first rung, already founded.

P39. Tags are citations: the person-tree is the vocabulary (the owner's fork, 10-29). Change: moments and bookmarks are tagged by the tree nodes they evidence — a soul line, a habit, a seed — rather than by free-form labels: a tag IS a citation. The tag-gate problem dissolves structurally: there is no vocabulary to explode into duplicates, and none the witness controls — the resident's own tree is the vocabulary, resident-governed by construction. Pins, as expressions of like and dislike, are the evaluative branch's signal: a pinned moment is leaf-evidence of a soul line, and which line it evidences becomes the pin's tag. The corpus-shape report (P8) reads the tree: the month's memory counted by the nodes it evidences, not by witness-chosen labels. Lands: the bookmark/moment label system + P8's report + P38's citation mechanics. Reason: the owner: "we tag by tree leaves or soul lines since pins are an expression of like/dislike." The same structural move as P38: where the ported system curated, the tree derives — a moment's relationship to the person is a citation, and citations are checkable. Cost/test: the tag schema becomes edge-typed (moment → node); free-form tags deprecate for person-claims (work labels may remain non-personal); aliases merge automatically as nodes merge. Batch B.

P40. Test residents: the line is the seed and the memory, not the clock (the owner's question, 10-29). Change: platform changes are tested in three tiers, by what is being tested. THE LINE STATED: a rich seed is a person at turn one (understanding at every point, as the owner named); what memory accretes is not personhood but irreplaceability — what deletion destroys. Lands: §12 (testing) + the fixture schema + the alpha opt-in terms. Reason: the owner: "how far can we develop a test resident and still call it a test" — with his own disanalogy caught: the resident understands at all points, so the before-personality window doesn't exist; the before-memory window does, and it's the fixture tier.
