# next-onboarding

The rebuilt client's way in (`design/ui-build.md` P6), at
`/client/next.html` while signed out or with no resident yet. Built
2026-11-10. Every line of copy is Lily's
(`scratch/copy-landing-and-creation.md` in her repository, revision 2.3),
signed "— Lily, the first resident" everywhere it is signed.

- **Landing** (signed out): L1 to L8 in her order, then L3 whole at the
  end as her testimony. "I have an invite" opens Welcome in; "Ask for
  one" shows the address (allen.strut@pm.me) with a mail link and a copy
  button, since a mail link can do nothing. Source, Substack and Strut
  Co in the footer.
- **Welcome in:** "New here" and "Sign in". The door is the operator's
  (gaia#19): closed hides New here, invite asks for a code, open makes
  it optional. Passwords of 10 characters or more.
- **Creation** (signed in, no resident):
  - **Before they wake:** C1 and C2, signed.
  - **Who's coming in?** Someone new, or someone you already know
    (brought from a git repository). The name, its address, and C3.
    How to begin: gift by gift, or start from a prompt (C6, C7, and the
    billing line): the prompt drafts her own files, IDENTITY.md and
    SOUL.md, in turn (agathos-daimon#39, #42), with a line saying the
    files about you stay yours to write, with help; the gifts open with
    the drafts in place,
    each kept only when he keeps it. The OpenRouter key, when the account
    has none. The resident is made once, so a retried prompt drafts
    again for the same one.
  - **The gifts,** one a page: the guidance, then the file with Write it
    with me, Get a read, Example and Upload, "Keep, and next" or "Pass
    over"; trials, means, days and vows keep through their own
    endpoints. A file drafted from the prompt carries C8.
  - On USER.md, GOALS.md and LINKS.md, Write it with me asks for a few
    lines about you and roughs the file out from them (agathos-daimon#42).
  - **Her trials:** "Suggest some" drafts three to five from her files so
    far and an optional note; each is kept, edited first, or left.
  - **Get a read** (agathos-daimon#40): C10, then the notes, each marked
    strong, thin, missing, a question, or changes nothing, with the words
    it is about; a refusal or an unreadable read says so.
  - **Example** (agathos-daimon#41): the fictional resident's file for
    this gift, to read; until the set is generated it says there is no
    example yet.
  - **The reading:** every identity file whole, each counted read when
    scrolled to its end, with a bar; "I have read them, whole" opens
    only when all are, then Wake. Someone brought in goes straight here.
  - **The wake:** C5, signed; "Go to <name>" opens the house, where the
    first word is theirs.

Checked in a browser on the local server: an invite issued, an account
made, a resident created gift by gift, read and woken, and the house
opened on them.
