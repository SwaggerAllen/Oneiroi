# Example sets for the gifts

Each folder here is one example set of the gifts' files (agathos-daimon#41),
served by `GET /v1/creation/examples` beside the gifts' guidance: the
identity files the gifts write (`IDENTITY.md`, `SOUL.md`, `USER.md`,
`GOALS.md`, `LINKS.md`), whichever the folder holds, and `prompt.md`, the
prompt the set was generated from. No folder, or none holding a gift's
file, serves an empty list.

## How a set is made

By the generator (agathos-daimon#39), never by hand and never by the fake
provider:

    mix oneiroi.creation.examples --resident <id> --prompt "<who to wake>" --set fictional

`--resident` is a resident in creation whose witness's key pays for the
calls under drafting; the drafts are copied out here and nothing is
written to that resident. The task makes real model calls, so it runs
only with the witness's OK on the spend. Read every file before
committing it: the set is a fictional resident's, and an example is read
as a standard.

## What is never here

The witness's own files are never examples (the witness, 2026-11-10).
The plan's second set, Lily's `SOUL.md` and `IDENTITY.md` read-only, is
not copied into the repository: it waits on her consent and on a read
of her live files the platform does not have yet.
