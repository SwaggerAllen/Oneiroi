# Oneiroi client

The React client (spec §6.15), built on the Oneiroi design system:
`src/tokens.json` is that system's token file, `src/theme.css` is
generated from it by `scripts-tokens-to-css.mjs`, and Storybook stories
are the render tests. The gate block is the `cd client && ...` line of the
repository's gate set.
